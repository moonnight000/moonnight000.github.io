个人邮件备份

隐私政策

生效日期：2026-10-26。适用于“个人邮件备份”本机应用。该应用仅供账户所有者个人使用，目前处于配置与验证阶段。

访问哪些数据、用于什么目的

应用通过 Google 官方 OAuth 请求 Gmail 只读权限（gmail.readonly）。为核验账户、发现新增或发生变化的邮件、防止重复备份和验证备份完整性，应用可能读取 Gmail 账户地址、邮件标识、标签、邮件头、正文、附件及邮箱变更记录。数据仅用于用户授权的个人邮件备份和必要故障排查。

保存与传输

授权并核验通过后，刷新令牌保存在该 Windows 用户的凭据管理器中；短期访问令牌仅在本机进程内存中使用，不写入文件或日志。凭据管理器按 Windows 用户提供保护，同一用户身份下运行的程序仍可能读取相关凭据，它不提供应用之间的完全隔离。客户端配置保存在限制本机访问权限的目录。本机可能保存邮件原文、备份进度、内容散列值和核验记录。

用户配置的备份邮件副本会传送并保存在其本人指定的 QQ／Foxmail 邮箱。Google 和 QQ／Foxmail 各自按其服务规则处理所托管的数据。应用不将邮件或授权令牌发布到本网站或公开代码仓库。

用途限制

本应用不出售 Google 用户数据，不将其用于广告投放、信用评估或训练通用人工智能模型，不用于与个人邮件备份无关的目的。维护人员仅在用户明确授权的故障排查范围内访问必要数据。

本应用对从 Google API 接收的信息的使用及向其他应用传输此类信息，将遵守 Google API 服务用户数据政策，包括其 Limited Use（有限使用）要求。

保留、停止与删除

邮件备份和核验记录保留至账户所有者主动删除。停止程序不会自动删除 Gmail 原件、QQ／Foxmail 副本或本机记录。用户可在 Google 账号的第三方访问权限设置中撤销本应用授权，并停止本机运行任务；撤销授权后应按需删除对应的本机授权凭据。删除邮件副本应由账户所有者在相应邮箱或本机明确操作，应用不会将关闭服务解释为删除邮件的许可。

网站与联系

这些说明页不提供邮箱登录、不接收授权码或邮件上传，也不嵌入广告或分析脚本。网站托管方可能按其政策保留常规访问日志。有关本应用的数据处理问题，请使用 Google 授权页面列出的用户支持邮箱联系维护者。

数据用途发生变化时，应先更新本政策并取得必要授权；本政策不会替代 Google 或邮箱服务提供方的条款。
